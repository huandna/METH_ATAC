甲基化C位点检测结果：

结果文件说明：

*.mC_level_Identification_stat.txt.gz   每个样品甲基化C位点鉴定结果
 (1) Chromosome：染色体编号
 (2) Position：该位点在染色体上的位置
 (3) Strand：该位点在染色体上的链信息
 (4) mC counts：支持甲基化的read数目
 (5) umC counts：支持非甲基化的read数目
 (6) methylation level: 该位点甲基化水平, 计算公式为：mC counts/(mC counts+umC counts)
 (7) Context：C位点类型
 (8) Pvalue：二项分布检验的p value
 (9) Corrected pvalue：校正后的p value
